## 🟡 현-4. 글쓰기 임시저장의 사진이 **조용히 사라진다** — 기-5의 실제 재현

진호님 관찰: *"경고 없이 나가졌고, 다시 글 작성 들어가보니 사진이 남아 있지 않아"*

### 두 가지가 동시에 확인됨

**(가) 기-13(나) 확인** — 사진만 올리고 나가면 경고 없음
`write/page.tsx:62` `useUnsavedGuard(!!(title || content))` — 이탈 경고 조건에 `images` 없음 ✅

**(나) 기-5의 실제 재현 — 예상과 다른 경로**
```js
// write/page.tsx:119-123
try {
  localStorage.setItem(DRAFT_KEY, JSON.stringify({ ..., images }));
} catch {}   // ← 실패를 통째로 삼킴
```
사진은 base64라 1장에 수백KB~1MB입니다. **draft에 통째로 들어가 용량을 초과하면 저장 자체가 실패**하고, 아무도 모릅니다.

→ 기획팀은 기-5가 "좋아요·저장"에서 터질 거라 예상했는데, **실제로는 글쓰기 임시저장에서 먼저 터졌습니다.**

**(다) 기-13(가)는 재현 불가**
"`discardDraft`가 사진을 안 지운다"는 지적은 **애초에 사진이 저장되지 않으니 지울 것도 없습니다.**
코드상 누락(`setImages([])` 없음)은 사실이나, 진호님 환경에서는 증상이 나타나지 않습니다.
